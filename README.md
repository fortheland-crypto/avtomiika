# 🚗 Telegram-бот для Автомойки (Демо-версия)

Рабочая демо-версия Telegram-бота для фиксации заезда автомобилей, учёта времени в боксе (>1 мин), расчета чеков по прейскуранту (в тенге ₸) и ведения подробной дневной статистики.

---

## 📌 Ключевые возможности

1. **Быстрая фиксация заезда в 2 клика**:
   - Выбор свободного бокса (`Бокс №1`, `Бокс №2`, `Бокс №3`, `Бокс №4`)
   - Выбор категории авто из прейскуранта (без ввода номеров)
2. **Прейскурант и расчёт чека (в тенге ₸)**:
   - 🚗 `Легковая машина` — **3 000 ₸**
   - 🚙 `Джип / Большая машина` — **5 000 ₸**
   - 🚗✨ `Легковая (Комплекс)` — **4 500 ₸**
   - 🚙✨ `Джип (Комплекс)` — **7 000 ₸**
3. **Учёт времени и защита от случайных нажатий**:
   - Машина считается вымытой и фиксируется в дневном подсчёте, если она находится в боксе **> 1 минуты** (или выехала по кнопке).
4. **Мониторинг активных боксов**:
   - Отображение текущих машин в боксах с таймером в реальном времени.
   - Выписка чека при нажатии `🏁 Выехал / Чек`.
5. **Аналитика и Статистика за день**:
   - Всего заехало машин
   - Количество подтверждённых моек
   - Общая дневная выручка (₸)
   - Средний чек (₸)
   - Подробная детализация по категориям авто и по каждому боксу
6. **⚡ Режим «Демо-смена» для презентации**:
   - 1 кнопка — мгновенное заполнение базы за сегодня 14 прошлыми заездами + 2 активными машинами прямо сейчас! Вы можете показать готовую аналитическую панель прямо на слайдах или живой презентации.

## 🚀 Быстрый запуск

### 1. Получение токена бота
1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather)
2. Напишите команду `/newbot` и следуйте подсказкам
3. Скопируйте полученный **HTTP API Token**

### 2. Настройка файла `.env`
Откройте файл `.env` в папке проекта и вставьте ваш токен:
```env
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
```

### 3. Запуск бота
В терминале выполните:
```bash
./venv/bin/python main.py
```
*(Или `python main.py`, если используете системный Python)*

---

## 🧪 Проверка бизнес-логики без Telegram
В проекте есть скрипт тестирования всех расчётов:
```bash
./venv/bin/python test_bot_logic.py
```

## 📂 Структура проекта
- `config.py` — прейскурант цен в ₸, список боксов и настройки
- `database.py` — работа с БД SQLite (`carwash.db`), подсчёт статистики и генерация демо-смены
- `keyboards.py` — меню и интерактивные кнопки
- `handlers.py` — логика обработки команд Telegram
- `main.py` — точка запуска бота
- `test_bot_logic.py` — автономный тест бизнес-логики
